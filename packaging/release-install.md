
### Install

**Linux:** download `Culm-<version>-x86_64.AppImage`, make it executable (`chmod +x Culm-*.AppImage`) and start it.
With [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) it gets a menu entry and updates itself.

**Windows 10/11:** run `Culm-<version>-windows-x64-setup.exe` (installs for you only, no admin rights needed).
Culm isn't signed yet, so Windows may show "Windows protected your PC": click **More info → Run anyway**.

**macOS 13 or newer (Apple Silicon and Intel):** open `Culm-<version>-macos.dmg` and drag Culm to Applications.
Culm isn't notarized by Apple yet, so the first start is blocked: open **System Settings → Privacy & Security**,
scroll down to the message about Culm and click **Open Anyway** (once per downloaded version).

Culm tells you when a new version is out; on Windows and macOS its "Update to …" button opens this page.
`SHA256SUMS` lists the checksum of every file.
